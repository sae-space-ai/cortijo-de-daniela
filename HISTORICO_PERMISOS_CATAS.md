## 🗺️ Sistemas de cuadrículas

### Cuadrícula arqueológica

**Sistema estándar:** UTM ETRS89 / Huso 29N (EPSG:25829)

**Tamaños habituales:**
- **Prospección intensiva:** 10×10 m (100 m²)
- **Prospección extensiva:** 20×20 m (400 m²)
- **Excavación:** 5×5 m (25 m²) o 1×1 m (1 m²)
- **Sondeo:** 1×1 m o 2×2 m

**Nomenclatura típica:**
```
Cuadrícula A-1, A-2, A-3...
Cuadrícula B-1, B-2, B-3...
```

**Coordenadas de referencia para el Cortijo de Daniela:**
```
Esquina NO: X=232500, Y=4208500 (aproximado)
Esquina NE: X=233000, Y=4208500
Esquina SO: X=232500, Y=4208000
Esquina SE: X=233000, Y=4208000
```

### Cuadrícula minera (permisos de investigación)

**Sistema:** Cuadrículas reglamentarias de 1×1 km (100 ha)

**Referencia:**
- Hoja MTN50: 718 (Llerena) o 719 (Azaga)
- Coordenadas UTM del centro de la cuadrícula
- Denominación oficial del permiso

**Requisitos:**

**Plazo de resolución:** 3-6 meses

**Tasas:** Variables según tipo de intervención

        "materiales": "Cerámica común",
        "observaciones": "Sin estructuras"

        "type": "Polygon",

**Procedimiento:**
1. Crear cuadrículas en QGIS (plugin "Grid" o "MMQGIS")
2. Exportar como GeoJSON (WGS84 / EPSG:4326)
3. Importar en GEO-LAB: "⬆ Cuadrículas (GeoJSON)"
4. Visualizar sobre ortofoto y catastrar

## 📊 Base de datos de intervenciones históricas

### Estructura recomendada

```sql
CREATE TABLE intervenciones (
  id INTEGER PRIMARY KEY,
  expediente VARCHAR(50),
  proyecto VARCHAR(200),
  fecha DATE,
  tipo VARCHAR(50),
  responsable VARCHAR(200),
  municipio VARCHAR(100),
  paraje VARCHAR(200),
  coordenadas_x FLOAT,
  coordenadas_y FLOAT,
  utm_x INTEGER,
  utm_y INTEGER,
  superficie_m2 FLOAT,
  materiales VARCHAR(500),
  estructuras VARCHAR(500),
  cronologia VARCHAR(100),
  memoria_depositada BOOLEAN,
  observaciones TEXT,
  sha256 VARCHAR(64)
);

CREATE TABLE cuadrículas (
  id INTEGER PRIMARY KEY,
  intervencion_id INTEGER,
  denominacion VARCHAR(10),
  utm_no_x INTEGER,
  utm_no_y INTEGER,
  utm_ne_x INTEGER,
  utm_ne_y INTEGER,
  utm_so_x INTEGER,
  utm_so_y INTEGER,
  utm_se_x INTEGER,
  utm_se_y INTEGER,
  tamaño_m2 FLOAT,
  estado VARCHAR(50),
  FOREIGN KEY (intervencion_id) REFERENCES intervenciones(id)
);
```

## ⚠️ Consideraciones legales

### Protección del patrimonio

- **Zonas de servidumbre:** 100 m alrededor de BIC
- **Zonas de respeto:** 50 m alrededor de BIC
- **Prospección sin excavación:** Requiere autorización
- **Excavación:** Requiere proyecto técnico aprobado

### Propiedad intelectual

- **Memorias:** Depósito obligatorio en el Servicio de Patrimonio
- **Materiales:** Propiedad de la Administración
- **Fotografías:** Autorización para uso público
- **Datos:** Acceso público tras 4 años (Ley 16/1985)

### Responsabilidades

- **Daños al patrimonio:** Responsabilidad penal (art. 323 CP)
- **Excavación ilegal:** Sanciones administrativas y penales
- **Exportación ilegal:** Delito contra el patrimonio histórico
